# Moda Visual

**Moda Visual** — визуальный клиент-мод для Minecraft Java Edition на **Fabric**, ориентированный на выразительные эффекты, косметику и удобную настройку интерфейса.

> Проект находится на ранней стадии разработки. Описанные ниже возможности — планируемые функции, а не заявление о том, что они уже реализованы.

## Цель проекта

Создать лёгкий, настраиваемый и визуально цельный мод, который добавляет Minecraft красивые эффекты и инструменты персонализации, не меняя игровые правила и не предоставляя нечестных преимуществ в мультиплеере.

## Планируемые возможности

### Player Visuals
- **Motion Trails** — следы движения игрока с настройкой длины, цвета и затухания.
- **Fly Visual** — декоративные частицы, крылья и эффекты движения; без настоящего полёта и изменения физики.
- **Jump Effect** — кольцо или частицы в момент прыжка.
- **Landing Effect** — визуальная ударная волна при приземлении.
- **Run Trails** — короткие следы во время бега.
- **Aura** — орбиты, кольца и частицы вокруг собственного персонажа.
- **Pulse** — пульсирующее кольцо с режимами Expand, Contract и Expand + Contract.
- **Wings** — косметические анимированные крылья.
- **Glow** — мягкое свечение с производительным запасным вариантом, если шейдер недоступен.

### Combat Visuals
- **Hit Effect** — визуальная вспышка и частицы при попадании.
- **Damage Numbers** — всплывающие числа урона.
- **Hit Particles** — настраиваемые искры, звёзды, круги и другие частицы.
- **Critical Visual** — отдельный эффект критического удара без изменения механики.
- **Totem Animation** — косметическая анимация срабатывания тотема.
- **Kill Effect** — эффект исчезновения/победы после смерти сущности.

### World Visuals
- эффекты разрушения и установки блоков;
- следы стрел и других снарядов;
- декоративные следы выброшенных предметов;
- альтернативное визуальное оформление молний.

### Particles
Собственная система частиц с цветом, размером, скоростью, временем жизни и прозрачностью. Планируются ограничение количества, повторное использование объектов и отсечение дальних эффектов для снижения нагрузки.

### HUD и интерфейс
- собственный **ClickGUI**, открываемый клавишей Right Shift;
- категории модулей и поиск;
- переключатели, ползунки, выпадающие списки и настройка клавиш;
- **HUD Editor** для перемещения и масштабирования элементов;
- виджеты FPS, ping, координат, CPS, скорости и времени сессии;
- watermark **MODA VISUAL**;
- темы Moda Dark, Midnight, Aurora и Mono, а также пользовательские цвета.

### Настройки и конфигурация
Планируется сохранение модулей, параметров, клавиш, темы и расположения HUD в каталоге:

`.minecraft/config/modavisual/`

## Принципы разработки

1. **Сначала стабильность.** Каждый этап должен собираться и запускаться до добавления следующего большого набора функций.
2. **Только реальные реализации.** Не оставлять фиктивные обработчики, пустые методы и несуществующие API под видом готовой функции.
3. **Актуальный Minecraft API.** Проверять rendering API и Fabric API именно для 1.21.11, не переносить устаревшие примеры без проверки.
4. **Производительность.** Ограничивать частицы, избегать лишних выделений памяти и ненужной работы каждый кадр.
5. **Совместимость.** Проверять взаимодействие с Sodium и другими популярными клиентскими модами; не обещать совместимость до тестирования.
6. **Без изменения игровых правил.** Визуальные модули не должны давать реальный полёт, скорость, reach, автоматическое наведение или другие игровые преимущества.

## Сборка

Когда Gradle-проект и wrapper будут добавлены, сборка на Windows будет выполняться командой:

```powershell
.\gradlew.bat build
```

На Linux/macOS:

```bash
./gradlew build
```

Готовый JAR Gradle обычно размещает в `build/libs/`. До появления и успешного запуска сборки это только планируемая команда, а не подтверждение готовности артефакта.
